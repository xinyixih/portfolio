Why MathML took so long to be usable

MathML has been part of the HTML specification for years, but developers could not rely on it because browser support was uneven. Firefox supported it early and Safari had partial support, but Chrome removed its short-lived implementation and did not ship MathML again until Chrome 109 in January 2023. Because Chromium also powers Edge, Opera and many other browsers, most users could not see MathML for a long time, so developers used images or JavaScript libraries such as MathJax instead. Only once every major engine supported MathML Core could it be written directly in HTML with confidence.
